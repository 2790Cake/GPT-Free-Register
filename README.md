# AutoGPT Account Console - GPT 免费号注册机

> 全自动 ChatGPT 账号批量注册工具，无需手动操作，一键生成可用账号。

## 功能特性

- **全自动注册** — 自动完成邮箱验证、手机验证等全流程
- **批量生产** — 支持多线程并发注册，高效产出可用账号
- **账号管理** — 内置账号库存面板，已注册账号一目了然
- **开箱即用** — 单文件绿色版，无需安装环境依赖

## 使用方式

1. 下载 [AutoGPT-Account-Console.exe](AutoGPT-Account-Console.exe)
2. 双击运行，根据界面提示操作
3. 在「账号库存」面板中查看已注册的账号信息
